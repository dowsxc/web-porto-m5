# Iwak Neko — Personal Portfolio

Portfolio website pribadi dengan dark theme, animated ambient background,
particle effect, responsive layout, dan section About, Experience, Projects,
Skills, serta Contact.

## Struktur

```text
profile/
├── index.html
├── style.css
├── script.js
├── assets/
│   ├── profile.jpg
│   └── ...
└── README.md
```

## Menjalankan

Buka `index.html` langsung di browser.

Atau gunakan local server:

```bash
cd profile
python3 -m http.server 8000
```

Kemudian buka `http://localhost:8000`.

## Assets

Taruh foto profil di:

```text
assets/profile.jpg
```

Foto belum disertakan karena belum ada file foto yang diberikan.

## Catatan

Ganti URL GitHub dan LinkedIn di `index.html` dengan akun asli.
